A next question for this project is how to separate the past used for training from the future used for evaluation.

Write down a simple baseline, the evaluation window, and the metric that matters. Together, they give future experiments a clear point of comparison.

The post training step raises a useful set of questions: what is the starting model, what new information should it adapt to, and which behaviors should improve?

Slab is the current climbing focus. This route is a place to notice what feels more balanced, what feels uncertain, and what changes from one attempt to the next.

After a session, capture one move and a small adjustment that changed how it felt. A few specific details can be more useful than a long recap.

02 / 03 Climbing focus

A focus for the next gym note: what was happening at the feet during a move that felt tricky?

A photo or short description can help capture the detail. Focus on what was noticeable: placement, pace, and where the movement felt settled or rushed.

Give the page
a good foundation.

A site is easier to navigate when its structure says what each part is for. This basecamp uses a header, navigation, main content, sections, and a footer instead of treating every block as a generic container.

Headings make the outline readable. Links take you somewhere; buttons perform an action. The skip link gets straight to the main content.

The homepage’s desktop columns become a single stack on small screens. Flexible widths, wrapping rows, and a few layout breakpoints let the same content fit the available space.

The map follows the same idea: hold positions scale with the wall, while their touch targets stay large enough to use. The notes move underneath when the columns get too narrow.

03 / 04 Completed build checkpoint

More than one way
to make a move.

The climbing holds can be reached with Tab and selected with Enter. With a hold focused, arrow keys move between checkpoints; Home and End reach the first and last hold.

A visible focus ring shows where you are. The selected note is announced, and motion preferences are respected. Without JavaScript, the holds still link to readable notes below the map.

The useful bit

Interaction should make the route easier to follow, however you navigate.
